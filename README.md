# E-Commerce-Sales-Analysis-
📈 E-Commerce Sales Analysis Using Pandas

This project demonstrates how to analyze e-commerce sales data using Python and Pandas.

It performs revenue calculations and extracts meaningful business insights such as total revenue, category performance, monthly trends, regional analysis, and top-performing products.

🛠 Technologies Used

Python 🐍

Pandas 🐼

📌 Features

Calculates total revenue

Performs category-wise revenue analysis

Analyzes monthly sales trends

Identifies the best performing region

Extracts top 5 products based on revenue

Generates and exports a summary report
